# NeuroGrid product

<!-- impeccable:product-schema 1 -->

NeuroGrid gives chat visitors and compute contributors equal prominence. Visitors try short prompts and see the model pass through three partitions. Contributors connect a Windows or Linux desktop node, choose CPU limits, and earn simulated credits for verified inference.

The website uses React, TypeScript, Tailwind and shadcn-style primitives. DeepSpace provides authentication, data synchronization and hosting. A trusted coordinator schedules three ten-layer CPU shards of SmolLM2-135M-Instruct and settles requests against a fixed 100,000-credit supply. Credits have no monetary value.

Live coverage and recent settlements come from the coordinator. The interface explains unavailable capacity and credits refunded after unsuccessful requests.
